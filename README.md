# ModelHarbor

可视化编辑 opencode、Kilo Code（kilocode）、MiMo Code（mimocode，小米）、pi、oh-my-pi（omp）、DeepSeek Harness（DSH）、ZCode 与 WorkBuddy 配置文件的桌面 GUI 工具。

Rust + egui 构建，单文件可执行程序，无需安装运行时。

## 功能特性

- **多页面编辑**：顶栏图标切换页面；加载任意一份配置后各页共享同一份数据，修改即时同步（provider / model 顺序亦跨页同步）
- **多格式互转**：任意加载、任意保存。跨格式写入只接管 provider 容器（条目与顺序以界面为准），目标文件其余配置保留，覆盖前自动备份为 `.bak`
- **同源格式合并支持**：Kilo Code 与 MiMo Code 都是 opencode 的 fork，配置 schema 的**字段与结构一致**（顶层 `provider` / `agent`、`options.baseURL`、`models.<id>.limit.context|output`），因此三者共用一套解析与序列化实现，差别只有配置目录名、主配置文件名与图标。三者内容形状一致，**判别按配置路径**（目录名 / 文件名）认领，无路径线索时回落 opencode。注意三家的 **required 并不相同**（mimocode 额外要求 `modalities` 成对），写盘时按目标方言补齐
- **方言表单**：各页按自身格式显示字段与枚举，没有的字段不占位；协议（npm / api）在 opencode 系 / pi / omp / DSH 四类格式间共用一份数据，跨页同步
- **卡片式管理**：Agents / Providers 增删改复制、拖拽排序、折叠展开（折叠状态会被记住）；模型参数与推理档位编辑
- **获取模型**：一键从提供商的模型列表接口拉取模型，多列勾选，勾选未配置的模型即新增
- **延迟 / 连通性测试**：标题行一键测全部厂商连通性；模型延迟为单模型手动探测。带防封号保护（检测到系统代理 / VPN 时默认禁用，可勾选「代理支持」放行；同厂商探测间隔 ≥5 秒、串行、流式测首字、UA 按协议伪装白名单客户端）
- **查询用户数据**：对有 `sk-` key 的 provider 发起只读管理请求，一次取回该站点能拿到的全部账号数据（余额 / 已用 / 今日 / 近 7 天 / 请求次数 / 分组 / 签到状态）。填了**面板访问令牌**（PAT）可额外拿到账号级真实余额与已用
- **配置预览 / 编辑**：右侧面板实时显示待保存内容，JSON / YAML 语法高亮、可直接编辑（改动实时应用并自动保存），支持 Ctrl+F 查找、拖动分隔条调整宽度
- **凭据处理**：各格式按自身方式读写密钥（DSH 为 `apiKeyEnv` 引用 + 同级 `.credentials.yaml`），加载自动读取、跨页同步、保存写回
- **分页保存与 WSL 同步**：每页独立保存按钮与写入路径；手动指定过的路径按页面记住，下次启动优先打开该页；勾选「WSL同步」且对应 agent 已安装时同步写入
- **外观**：主题 8 种（深色系 / 亮色系各 4），形状 8 种（标签 / 圆润 / 精致 / 极简 / 云朵 / 浮雕 / 石板 / 色带）。两者正交——主题管颜色，形状管控件长相。卡片折叠与悬停带过渡动画
- **界面设置持久化**：主题、形状、保存格式、密钥显隐、WSL 同步、卡片折叠、代理支持开关、各页路径写在 `%USERPROFILE%\.modelharbor\settings.json`；只存界面选择与开关，不存密钥与配置内容

## 构建运行

```bash
cargo build --release
```

产物为单文件可执行程序：`target/release/ModelHarbor.exe`
